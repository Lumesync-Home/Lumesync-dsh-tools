# lumesync-inhand（移动层）

让 DSH Web 在**窄屏/手机**上可用。纯浏览器侧实现，主机侧只保留空壳入口。

## 功能

- **侧栏抽屉**：窄屏下侧栏改为可滑出抽屉
- **缩放守卫**：双击与双指缩放被拦住（避免误缩放）
- **viewport meta**：补齐移动端视口设置
- **安全区**：刘海/底部手势区内边距（`env(safe-area-inset-*)`）
- **稳定输入框**：输入聚焦不跳动、不被遮挡

## 结构

- `lib/index.js` — 主机侧占位（`inject: []`，`apply()` 为空），只为让插件行在 roster 里解析
- `lib/client.js` — 浏览器侧：全部功能所在

## 安装

见仓库根 `README.md`。挂载后重启 DSH；仅窄屏生效，桌面宽屏不受影响。

## 回退

从 profile `dependencies` 移除 → 重启 DSH。不改任何持久数据。

## 注意

- 与外观层独立，可单独安装
- 若同时装旧的 `lumesync-mobile`，会重复注入，只留一个
